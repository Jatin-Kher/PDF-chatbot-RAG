Retrieval-Augmented Generation (RAG) is an AI architecture that combines information retrieval with large language models to generate accurate and context-aware responses. Instead of relying only on the data used during training, a RAG system first retrieves relevant information from external sources such as PDFs, databases, websites, or vector stores, and then provides that information to the language model as context before generating an answer. This helps reduce hallucinations, improves factual accuracy, and enables the model to answer questions about private or up-to-date data. RAG is widely used in applications like chatbots, document question answering, enterprise search systems, and AI assistants.
